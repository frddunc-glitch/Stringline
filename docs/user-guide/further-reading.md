# Further reading

## SimSig

- [SimSig](https://www.simsig.co.uk/): the simulations, their manuals and the forum.
- [Interface Gateway](https://www.simsig.co.uk/Wiki/Show?page=usertrack:interface_gateway) on the SimSig wiki: what the gateway sends, its topics, and logging in to it for payware sims. Written for programmers.
- The SimSig forum's [Interface Gateway board](https://www.simsig.co.uk/Forum/BoardView/266), under Customising SimSig: questions and projects that use the gateway.
- [SimSig wiki](https://www.simsig.co.uk/Wiki): the user manuals, including the Loader and the sims' own pages.

## Stringline

- [Source code and README](https://github.com/frddunc-glitch/Stringline), including the command-line tools for recording, replaying and drawing graphs.
- [Releases](https://github.com/frddunc-glitch/Stringline/releases): downloads and what changed.
- [Issue tracker](https://github.com/frddunc-glitch/Stringline/issues): report a problem or ask for a feature.
- [Design documents](https://github.com/frddunc-glitch/Stringline/tree/main/docs): how Stringline works inside, for the curious.

Stringline is an independent project. It is not affiliated with, endorsed by or supported by SimSig or its developers.
