# Keyboard and mouse

## Keys

| Key | Does |
|---|---|
| F1 | Opens this guide at the page for the panel or window you are in |
| F5 | Session ▸ Connect to SimSig… |
| Ctrl+O | Session ▸ Open replay… |
| Ctrl+T | File ▸ Load timetable… |
| Ctrl+E | File ▸ Export ▸ Graph as PNG… |
| Ctrl+P | File ▸ Export ▸ Graph as PDF (A3 landscape)… |
| Ctrl+Z | Plan ▸ Undo |
| Ctrl+Y, Ctrl+Shift+Z | Plan ▸ Redo |
| Ctrl+, | Tools ▸ Options… |
| Ctrl+1 … Ctrl+9 | Show the first to ninth corridor |
| Alt+F4 | File ▸ Exit |

With the graph focused (click it first):

| Key | Does |
|---|---|
| Space | Turn following now on or off |
| Esc | Clear the selection; during a drag, drop the drag |
| ← → (↑ ↓ when vertical) | Nudge the picked grip by 15 s |
| Shift + arrow | Nudge the picked grip by 1 min |
| B + drag | Draw a block |
| Shift while dragging a grip | Snap to 1 s, not 15 s |
| Alt + drag | Retime the selected train from the point pressed |

## Mouse on the graph

| Do | On | Does |
|---|---|---|
| Wheel | Anywhere | Zoom in time, about the mouse |
| Ctrl + wheel | Anywhere | Zoom along the corridor |
| Shift + wheel | Anywhere | Pan in time |
| Drag | The background | Pan |
| Hover | Anything | Show its details |
| Click | A train | Select it and show its grips |
| Click | The background | Clear the selection |
| Click | A conflict ring or band | Focus the conflict and show suggestions |
| Click | A grip | Pick it, for nudging with the keys |
| Drag | A square grip | Retime from that point |
| Drag | A bar grip | Change the dwell |
| Drag | The round handle, or the selected line | Retime the rest of the run |
| Right-click | A train | The train's menu |
| Right-click | The background or a disruption | Add or edit a block, speed restriction or note |
| Right-click | A note | Edit or remove it |

## Elsewhere

| Do | On | Does |
|---|---|---|
| Click | A row in the train list, Conflicts or Delays | Select that train or conflict |
| Double-click | A row in the train list | Centre the graph on the train's last report |
| Double-click | A splitter | Hide or show the panel beside it |
| Double-click | A cell in the train detail's Plat, Line or Plan columns | Edit it |
